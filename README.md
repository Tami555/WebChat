# Tobbi-Dog: WebChat 📱

## Версия v.1.0 (реализовано)

### Аутентификация
- Регистрация/Авторизация по номеру телефона с подтверждением через SMS-код
- JWT-токены для работы авторизованных пользователей

### Чаты
- Диалоги (личные чаты между двумя пользователями)
- Группы (чаты с несколькими участниками)
- Создание диалогов и групп

### Сообщения
- Создание сообщений (текстовые, с файлами)
- Отправка через WebSocket (для пользователей, реальное время)
- Отправка через HTTP (для разработчиков)
- Чтение сообщений с пагинацией
- Статусы прочтения сообщений
- Файлы: загрузка, скачивание, удаление (локальное хранение)

### Инфраструктура
- Redis для отслеживания онлайн-статуса пользователей
- Pub/Sub для обмена сообщениями

### Тестирование
- Написаны тесты для всех HTTP-эндпоинтов
